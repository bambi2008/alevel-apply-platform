# 桥申 · 项目开发守则

> 这份文档是**给 AI(Claude）和团队的工作纪律**。每次开始做新课题、新专业、新功能前，**先读这份守则**。
> 它的存在是为了解决一个反复出现的问题：AI 每隔几轮就忘记"先做功课再设计"，滑回凭空拍脑袋。
> **用法：新对话里，只要说"按开发守则来"，AI 必须先执行下面的铁律。**

---

## 一、课题设计铁律（最重要，每次做新专业/新课题前必须执行）

做任何一个新的在线课题（尤其是新专业方向），**必须按以下顺序，严禁跳过第 1 步凭空设计：**

### 第 1 步：先搜真实案例（不许省）
在设计任何课题前，先用联网搜索收集真实资料：
1. **头部背景提升项目**（Polygence、Pioneer、Crimson、各类 research program）在**该领域**的真实课题：长什么样、什么难度、什么方向、如何组织。
2. **成功申请案例**里，学生在该专业做过什么样的项目/课题。
3. **该专业的英国 / 港校招生官真正看重什么**、什么样的背景提升有说服力。

### 第 2 步：用真实资料校准
用搜到的真实案例，校准课题的**方向、难度、含金量**——而不是 AI 凭空想象。

### 第 3 步：才动手写课题

> ⚠️ 教训记录：工程、CS、经济、生物、数学几批课题，AI 都是先凭空设计、被用户提醒后才回头搜。这是错误做法。**先搜，再写。**

---

## 二、每个课题必须具备的要素

一个合格的在线课题（`lib/background/projects.ts`）必须包含：

1. **专业工具**（primaryTool）：指定真实、专业、学生可及（最好免费）的工具。
   - 工程：ANSYS 学生版（Mechanical / Fluent / Fatigue）、Fusion 360
   - CS/数据：Python + scikit-learn、Colab、Kaggle
   - 经济：Python(statsmodels)/R、世界银行/FRED 数据
   - 生物：NCBI BLAST、Biopython
   - 数学：Python(numpy/sympy)、Desmos
   - 商科：Excel 为主 + 可选 Python，真实财报/公开数据
2. **量化验收指标**（每阶段 metrics）：如应力、安全系数、升阻比、F1、回归系数、L/D 等。
3. **基础线 / 挑战目标**（baseline / challenge）：分层，都要量化。
4. **反思与延伸**（reflection）：4 个引导问题。**英国招生官最看重"反思"，不是"做了什么"。**
5. **PS 用途**（psUse）：说明产出如何用于英国 UCAS 个人陈述 / 港校申请。
6. **AI 教练**：阶段成果反馈（工程导师视角）+ 反思反馈（文书教练视角，不代写）。

## 三、关键产品原则

1. **诚实定位**：完成记录只写"在桥申平台完成了 X 课题，产出 Y，学生本人完成"。**绝不写"官方认证/大学认可"**（合规风险）。真认证极难（Pioneer 靠大学审计三年），我们不吹。
2. **不代写文书**：AI 只做教练——批改、建议、追问。UCAS 有相似度检测，代写/AI 生成有风险。个人陈述必须是学生本人真实想法与文字。
3. **英国 vs 香港**：
   - 英国（尤其牛剑/罗素/G5）：**只看与专业相关的学术深度**（super-curricular），几乎不看课外活动。LSE 建议 PS 约 80% 写学术。
   - 香港（港大/科大/中大）：**综合评估**（holistic），看学术 + 研究项目 + 实习 + 领导力，但要连接到成长与洞察。
4. **AI 无一手把握的领域**（商科、经济、生物、数学等非工程方向）：产出后必须提醒"上线前需懂对应专业的人审核"。这是"Claude 做工具、用户团队审核把关"的分工。

## 四、产品路线图（基于用户太太亲历申请 + 真实录取数据）

**已定顺序：**
1. **背景提升（在线课题）——用力做，最大差异化**（进行中）
   - 已完成：工程 6 个（机械3+航空3）、CS/经济/生物/数学 各 1 个样板
   - 进行中：商科（申请量第一，最大缺口）
   - 待办：商科做完后，加厚 CS/经济/数学/工程 到每方向 3 个
2. **考试培训加厚 + 学科竞赛**（数学/物理/生物等竞赛，与背景提升联动）
3. **文书教练**（不代写，只批改/建议/追问；已在课题反思环节落地雏形）
4. **申请材料**（交互式填表助手，非代登录代填）

**录取数据结论（过去三年中国 A-Level 申英）**：商科申请量第一、CS 增长最快、经济/数学/工程是牛剑热门。→ 先补商科，再加厚 CS/经济/数学/工程。

## 六、技术备忘（协作用）

- 技术栈：Next.js 16 (Turbopack) + TS + Tailwind v4 + Prisma/Postgres + NextAuth v5 + next-intl。dev 端口 3100。
- **用网站必须同时开两个终端**：`pnpm db:start`（数据库，登录/上传/存数据靠它）+ `pnpm dev`（网站）。缺一即出错。
- 改完代码习惯先跑 `pnpm build`（一次性揪出所有缺失文件/类型错误），再 `git push`。
- Windows 应用文件：含 `app\[locale]\` 的批次要用"临时解压 + Copy-Item -LiteralPath"，避免方括号被当通配符导致文件没复制进去。
- AI 能力：DeepSeek（`deepseek-chat`，环境变量 `DEEPSEEK_API_KEY`），用于答题批改与课题 AI 教练反馈。
