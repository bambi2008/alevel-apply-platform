# 题库生产、审核与版本发布中心

## 目标

管理员在 `/admin/question-studio` 内完成题目起草、公式预览、来源登记、双重审核、版本比较和固定结构组卷。题库仍由 Git 管理，不新增数据库迁移。

## 工作流

1. `DRAFT`：作者编辑题干、答案、解析、来源和权利状态。
2. `SUBJECT_REVIEW`：等待学科审核。审核人确认唯一正确答案、推理与分值。
3. `TEACHING_REVIEW`：等待教学审核。审核人确认表述、干扰项、解析和学生体验。
4. `APPROVED`：允许进入正式发布包。

任何题目内容或来源字段发生修改，状态自动退回 `DRAFT`。开始新修订后，工作台会保存上一版题目并展示字段级差异。

## 权利门禁

只有 `OWNED` 和 `LICENSED` 可以发布。`LINK_ONLY`、`RESTRICTED` 和 `UNKNOWN` 都是阻断状态。官方题还应填写可核验来源链接。

## 本地存储与导出

- 浏览器工作区自动保存在 `localStorage`，键名为 `qiaoshen-question-studio-v1`。
- “备份”导出所有草稿，包括未完成内容和审核记录。
- “正式发布包”仅导出已批准且零 critical、零 warning 的题目，并附来源与审核记录。
- 发布包不会自动写入 `lib/tests/questions`；代码审核通过后再将结构化内容接入对应题库模块。

## 命令行发布门禁

导出“可审计工作区”后运行：

```powershell
pnpm audit:release .\question-workspace.json
```

命令会重新执行 schema、答案、分值、语义、教学、版权和双重审核检查。发现任何阻断或告警时返回非零退出码。

## 智能组卷

组卷器从现有专项练习库选择题目，按考试、题型、知识点和 1/2/3 难度目标生成确定性方案。同一蓝图始终得到相同题目，便于复核。方案会报告题量不足、难度目标缺口和答案位置偏斜。
