**产品名称**：待定（暂称 ApplyBridge / 桥申）
**版本**：v0.1 草稿
**作者**：产品团队
**日期**：2026 年 6 月

## 一、产品定位

### 1.1 一句话描述

为中国大陆 A-Level 学生提供 **自助式** 英国/香港大学申请 SaaS 平台，以 1/20 的价格替代传统中介，让学生掌控自己的申请旅程。

### 1.2 核心价值主张

- **省钱**：年订阅 ¥299～¥1,999，传统中介动辄 ¥2 万起
- **专业**：A-Level 专属数据库、精准成绩匹配、院校真实录取数据
- **自主**：学生自己完成申请，理解每一步逻辑，不被中介架空
- **安全**：不代写文书，AI 辅助构思，规避 UCAS 剽窃检测风险

### 1.3 目标用户

| 主要用户 | 描述 |
|---------|------|
| 主用户 | 国内就读 A-Level 课程的 Year 12/13 学生（15–18 岁）|
| 次用户 | 家长（关注费用、进度、院校排名）|
| 潜在 B 端 | 国内 A-Level 学校的升学指导老师 |

## 三、核心功能模块（MVP）

### 模块 1：成绩匹配与选校引擎

**目标**：学生输入 A-Level 科目和预测分，系统智能推荐匹配院校。

**功能点**：
- 输入界面：科目选择（下拉/搜索）+ 预测成绩（A*/A/B/C/D）
- 匹配算法：基于院校字段表中 `alevel_minimum` + `required_subjects` 进行过滤排序
- 结果展示：匹配院校卡片，显示录取率、排名、学费、城市
- 保存 Shortlist：学生可收藏最多 10 所学校进入"选校池"
- 智能提示：如"此专业要求数学 A-Level，你尚未选择"

**优先级**：P0（MVP 必须）

---

### 模块 2：申请日历与任务管理

**目标**：帮助学生不遗漏任何关键节点。

**功能点**：
- 系统根据选校池自动生成个性化截止日历
- 任务清单：注册 UCAS / 完善 PS / 联系推荐人 / 上传成绩单等
- 进度状态：待开始 / 进行中 / 已完成
- 提醒：微信推送 / 邮件 / 站内通知（截止前 30 天、7 天、1 天）
- 多阶段：早申 / 主申 / 放榜 / Clearing 各阶段独立视图

**优先级**：P0

---

### 模块 3：院校数据库

**目标**：替代中介的"内部信息"，让学生自主查询每所院校的真实要求。

**功能点**：
- 搜索与筛选：按国家/城市/联盟/专业/成绩要求/学费 多维筛选
- 院校详情页：涵盖 Section 1.1～1.7 所有字段
- 课程对比：横向对比最多 3 所院校的同类课程
- 入学考试信息：如 LNAT / UCAT 报名链接 + 备考资源
- 历史录取数据：往届成绩段分布（匿名数据）
- 奖学金信息：各院校面向大陆生的奖学金汇总

**优先级**：P0

---

### 模块 4：个人陈述（PS）辅助工具

**目标**：帮助学生自己写出高质量 PS，而非代写。

**功能点**：
- PS 结构引导：分模块填写（学术热情 / 课外活动 / 未来规划）
- AI 润色建议：指出逻辑不清、用词重复、结构问题（不代写句子）
- 字数计数器：实时显示字符数（上限 4000 字符）
- 版本历史：可保存多版本，对比修改
- UCAS 格式检查：提示不允许使用特殊格式符号
- 示例 PS 库：往届成功案例（脱敏）按专业分类

**优先级**：P0（AI 润色 Phase 2 可升级）

---

### 模块 5：文件与材料管理

**目标**：一站式管理所有申请材料，避免遗漏。

**功能点**：
- 材料清单模板：按目标国（UK/HK）和专业类型生成清单
- 文件上传：成绩单、语言成绩、护照等（存储加密）
- 推荐信协作：生成专属链接，推荐老师直接在线填写/上传
- 文件状态追踪：已上传 / 待完善 / 院校已接收
- 智能提醒：材料不完整时阻止提交模拟

**优先级**：P1

---

### 模块 6：社区与经验库

**目标**：利用往届用户数据形成口碑飞轮。

**功能点**：
- 录取报告（Offer Report）：用户分享成绩 + 录取结果（匿名）
- 按院校/专业/年份筛选往届案例
- 讨论区：问答形式，按标签（院校/签证/生活）分类
- 认证往届生标识：提升可信度

**优先级**：P1

---

### 模块 7：签证指南

**目标**：提供英国 Student Visa + 香港学生签证标准化指南。

**功能点**：
- 分步骤图文指南（UK / HK 各一套）
- 材料清单 PDF 下载
- 常见问题 FAQ
- 财力证明计算器（按学费 + 生活费计算所需存款额）

**优先级**：P1

---

### 模块 8：择校对比看板（同专业方向跨院校比较）

**背景痛点**：学生已确定专业方向（如经济学、计算机），但面对十几所都能申的院校时，不知道各校有什么区别。现有工具只做"能不能进"，不呈现"各所学校具体怎么样"。

**目标**：将同一专业方向下多所院校的关键维度并排呈现，信息透明化，让学生自己做判断。**平台只呈现事实，不给出推荐结论。**

**设计原则**：
- 只展示客观数据（排名、学费、课程结构、地点），不做加权评分
- 不显示"推荐指数"或"综合评分"，避免平台替代学生判断
- 每项数据标注来源和更新时间，保证可溯源

**功能点**：

- **专业维度排名**：同一专业方向下，各院校 QS 学科排名并排展示
- **课程结构对比**：必修课模块、选修方向数量、是否含实习年（Placement Year）、海外交换机会
- **城市与生活成本**：城市、平均月租参考区间、与伦敦的距离
- **学费对比**：各院校该专业的国际生年学费
- **录取要求对比**：典型 Offer / 最低 Offer / 是否需要笔试或面试
- **往届录取成绩分布**（社区数据积累后启用，标注为"用户自报告数据"）
- **对比表导出**：一键生成 PDF，方便与家长讨论

**不做的事**：~~加权评分卡~~、~~"推荐选这所"~~、~~AI 生成择校理由~~

**优先级**：P1（Phase 2 上线，数据结构依赖院校库扩充）

---

### 模块 9：入学笔试备考（Admissions Test Prep）

**背景痛点**：LNAT / UCAT / BMAT / MAT / TMUA 等入学考试，线下培训机构收费 ¥5,000–¥20,000，且内容高度重复、可标准化。这是中介费以外学生的第二大支出项。

**目标**：提供覆盖主流英国入学考试的线上备考资源，替代绝大部分线下培训需求。

**覆盖考试**：

| 考试 | 适用院校/专业 | 市场现有培训费 |
|------|------------|-------------|
| LNAT | 法律（牛津/UCL/KCL 等） | ¥8,000–¥15,000 |
| UCAT | 医学（绝大多数英国医学院） | ¥10,000–¥20,000 |
| MAT | 数学/CS（牛津） | ¥5,000–¥12,000 |
| TMUA | 数学/CS（剑桥/多院校） | ¥5,000–¥10,000 |
| BMAT | 医学（帝国/UCL，已停考参考历史题） | — |
| PAT | 物理（牛津） | ¥5,000–¥8,000 |
| ELAT | 英语文学（牛津） | ¥3,000–¥6,000 |

**功能点**：

- **题库**：历年真题 + 模拟题（按考试分类，持续更新）
- **专项练习**：按题型/难度/章节刷题，错题本
- **计时模拟考**：完整模拟考试时长和格式，自动评分
- **解析**：每道题附详细中文解析（初期 AI 生成 + 人工审核）
- **备考计划**：根据考试日期自动生成每日练习计划
- **分数预测**：基于练习数据预测当前水平，提示薄弱点
- **UCAT 专项**：VR / QR / AR / SJT 四个模块独立训练

**优先级**：P1（LNAT + UCAT 优先，覆盖最大用户群；其余迭代补充）
**商业价值**：此模块独立付费意愿极强，可作为单独加购模块定价 ¥299–¥499/科

### 模块 10：背景提升资源市场（Profile Resource Marketplace）

**背景痛点**：学生需要真实的学术/实践经历来支撑 PS 和推荐信，但不知道去哪找靠谱的渠道，中介借此收取高价"背景提升"套餐（¥5,000–¥30,000）。优质资源本身是存在的，问题在于信息不透明、入口分散。

**模式定位**：平台做 **To B 资源聚合**，不自己生产内容，而是接入合作机构，向学生提供可信的背景提升资源入口，按引流或成交抽佣。

**商业模式**：
- 资源方（B 端）入驻平台，填写结构化信息（类型/时长/价格/适合专业方向）
- 学生（C 端）通过平台发现、筛选、跳转或预约
- 平台收取导流佣金（CPS）或年度入驻费

**合作资源方类型**：

| 类型 | 具体资源 | 适合专业 |
|------|---------|---------|
| 学术竞赛 | 数学奥赛、物理竞赛、经济学竞赛、模拟联合国 | 理工 / 商科 / 社科 |
| 科研项目 | 大学暑期科研（国内/海外）、线上 Research Program | 理工 / 医学 |
| 实习平台 | 金融/咨询/科技行业虚拟实习、实体实习对接 | 商科 / CS |
| 在线课程 | Coursera / edX / FutureLearn 专业课（附结课证书） | 全专业 |
| 读书会/写作营 | 学术阅读小组、论文/文章发表辅导 | 文科 / 社科 |
| 志愿者项目 | 医院志愿者、社区服务、NGO 项目 | 医学 / 社科 |

**平台侧功能点**：

- **资源目录**：按专业方向 / 类型 / 价格区间 / 时长筛选，展示资源方基础信息
- **活动记录本**（学生侧）：结构化录入参与过的经历（时间/角色/成果），自动生成 PS 素材条目
- **"院校希望看到什么"参考**：各院校招生官公开表述的软性偏好，帮助学生对照选择资源
- **时间轴视图**：Year 10 → Year 13 的经历分布，识别空白期
- **PS 素材提取**：从记录本一键提取经历要点，辅助写 PS 活动段落

**资源方入驻标准**（保证质量）：
- 提供往届参与学生的录取结果（脱敏）
- 不允许虚假宣传"保录取"
- 用户评分低于 3.5/5 自动下架

**优先级**：P1（Phase 2）
**收入逻辑**：此模块对平台是纯轻资产——不需要自己生产资源，靠撮合抽佣。资源方也有动机入驻，因为获得精准的 A-Level 学生流量。

## 四、非功能需求

### 4.1 性能
- 首屏加载 < 2 秒（4G 网络）
- 院校搜索响应 < 500ms
- 支持并发 1,000 用户

### 4.2 安全与合规
- 用户上传文件加密存储（AES-256）
- 符合中国网络安全法 / 数据安全法
- 需进行 ICP 备案
- 不存储护照原件，仅元数据

### 4.3 国际化
- 界面语言：中文简体（主）/ 英文（辅）
- 时区：支持 Asia/Shanghai 和 Europe/London 双时区显示
- 支付：微信支付 / 支付宝 / 银联

### 4.4 端覆盖
- Web（PC 优先，兼容移动端）
- 微信小程序（Phase 2）

## 六、分期范围界定

### Phase 1：全工具集上线

> 目标：让学生用平台完成申请全流程的所有操作性任务，不依赖任何人工介入。

**纳入 Phase 1 的模块：**

| 模块 | 说明 |
|------|------|
| 成绩匹配与选校引擎 | A-Level 科目+预测分 → 院校推荐列表 |
| 申请日历与任务管理 | 个性化截止日历、任务看板、微信提醒 |
| 院校数据库 | UK Top 30 + HK 8，含字段表全部字段 |
| 择校对比看板（模块 8） | 同专业多校定性并排对比，不给推荐结论 |
| PS 编辑器 | 结构引导 + 字符计数 + 格式检查 + AI 润色 |
| 文件与材料管理 | 材料清单、上传、推荐信协作链接 |
| 入学笔试备考（模块 9） | LNAT + UCAT 优先，题库 + 模拟考 + 解析 |
| 签证指南 | UK/HK 签证步骤、材料清单、财力计算器 |
| 用户注册 / 订阅支付 | Free / Standard / Pro 三档 |

**Phase 1 不做：**
- 社区、案例库（无存量用户时无内容）
- 背景提升资源市场（需 B 端合作方招募）
- 人工辅导（无资源）
- 微信小程序（Web 先跑）
- B 端学校管理后台

---

### Phase 2：社区生态 + 资源市场

> 目标：用 Phase 1 积累的真实用户数据反哺平台，从工具升级为社区。

**2A：真实案例导入与社区**

- **录取案例库**：鼓励已录取用户提交脱敏案例（成绩 + 科目 + 录取院校 + PS 摘要），形成真实参考库
- **结构化案例模板**：统一格式导入，支持按院校/专业/成绩段筛选
- **讨论区**：问答 + 经验帖，按标签（院校/签证/考试/生活）分类
- **往届生认证**：已录取用户获得认证标识，提升内容可信度
- **Offer 看板**：每年放榜季实时汇总用户录取动态（匿名），形成热度话题

**2B：背景提升资源市场（模块 10）**

- 资源方入驻（竞赛/科研/实习/在线课程机构）
- 学生免费浏览，平台对资源方收入分成或年费
- 活动记录本：学生记录参与经历 → 自动生成 PS 素材条目

## 七、风险与缓解措施

| 风险 | 等级 | 缓解措施 |
|------|------|---------|
| 数据准确性（院校更新要求）| 高 | 建立每年 8 月更新机制；标注数据年份 |
| AI 生成不准确内容 | 中 | 限制 AI 为"建议"非"结论"；加免责声明 |
| 竞品跟进（新东方推出 SaaS）| 中 | 构建社区数据壁垒；先发优势 |
| 用户教育成本高 | 中 | 与 A-Level 学校合作推广；内容营销 |
| ICP 备案周期长 | 低 | 提前 3 个月启动 |
| UCAS 系统变更 | 中 | 订阅 UCAS 官方通知；快速响应更新 |
