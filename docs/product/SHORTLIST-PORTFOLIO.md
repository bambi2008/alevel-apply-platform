# 选校决策工作台与申请组合优化

## 目标

在“专业匹配”与“正式申请”之间建立候选决策层。学生可以先比较、平衡风险，再将最终候选转成申请，不必把每个感兴趣的专业都立即加入申请清单。

## 决策依据

- 复用现有逐科成绩、必修科目和 IELTS 匹配引擎。
- 展示典型成绩、英语要求、入学笔试、学费和 QS 排名等可核对字段。
- 分类仅表示当前档案与结构化门槛的距离，不表示录取概率。
- 数据缺失统一显示“待核对”，不使用猜测值补齐。

## 组合审计

- UCAS 有效志愿不得超过 5 个。
- 检查是否缺少匹配或稳妥选项。
- 冲刺与暂不建议项目超过一半时提示风险。
- 检查目标地区是否均有覆盖。
- 同一院校超过两个专业时提示集中风险。

## 工作流

1. 从成绩档案生成专业推荐。
2. 按专业方向和地区筛选。
3. 加入持久化候选清单，并选择最多四项横向对比。
4. 查看组合健康度和具体风险。
5. 将最终候选转为正式申请；UCAS 第六个有效志愿会被后端拒绝。
