# 全站智能提醒与消息中心

## 目标

把学生分散在备考中心、申请待办和申请时间线里的下一步行动，汇总为可处理、可去重、可关闭的站内提醒。消息中心不替代原业务页面，只负责告诉学生现在最值得处理什么，并把学生带回对应工作流。

## 提醒来源

- 备考任务：聚合今天待完成和历史逾期任务，按天生成，避免逐题轰炸。
- 申请待办：提醒未来 7 天内截止和最近 30 天内逾期的个人任务。
- 关键日期：根据入学年份与目标地区，提醒未来 30 天内的申请节点。
- 学习报告：最近 7 天有学习活动时，每个自然周生成一次报告入口。

每条消息使用 `userId + sourceKey` 唯一约束。重复同步只更新标题、正文、优先级和有效期，不重复创建消息，也不会重置已读状态。

## 用户能力

- 顶部铃铛显示未读数与最近五条消息。
- 消息中心支持全部/未读筛选、单条已读、全部已读和忽略。
- 用户可分别关闭备考任务、申请待办、关键日期和学习报告提醒。
- 桌面端和手机端共享同一套消息与偏好数据。

## 发布

部署时先执行：

```bash
pnpm exec prisma migrate deploy
pnpm exec prisma generate
```

邮件周报目前只保留偏好字段，界面明确标记为即将开放。外部邮件、短信或微信发送必须在配置真实供应商、退订机制和发送审计后启用。
