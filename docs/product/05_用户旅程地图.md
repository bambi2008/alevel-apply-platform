# 用户旅程地图

**用户画像**：李同学，17 岁，就读于上海某国际学校 A-Level Year 12，计划 2027 年秋入读英国或香港大学。
**目标**：在不依赖传统中介的情况下，独立完成英国/香港大学申请。

---

## 阶段总览

```
阶段一        阶段二        阶段三        阶段四        阶段五        阶段六
认知&探索  →  选校规划   →  材料准备   →  提交申请   →  等待决定   →  录取后准备
[Year 12]    [Year 12]    [Year 12-13] [Year 13秋]  [Year 13冬春] [Year 13夏]
```

---

## 阶段一：认知与探索（Year 12 上学期）

### 学生行为
- 在小红书、知乎、微信群看到同学讨论留学
- 搜索"A-Level 申请英国 流程"、"港大需要什么成绩"
- 家长咨询中介公司，被报价 ¥3–5 万
- 加入留学群，被各种推广信息轰炸

### 情绪状态
😰 焦虑（信息太碎、不知从何下手）
😤 抗拒（中介费太贵，家长争论）

### 痛点
- 不知道 A-Level 哪些科目组合对申请有利
- 看不懂 UCAS 官网（全英文）
- 无法判断中介说的话是否真实

### 平台介入机会
- **内容营销入口**：小红书/知乎攻略文，引导到平台
- **免费工具钩子**：无需注册即可使用成绩匹配（看结果需注册）
- **价格对比落地页**：直接展示"传统中介 ¥30,000 vs 本平台 ¥999/年"

---

## 阶段二：选校规划（Year 12 下学期，约 2 月–6 月）

### 学生行为
- 整理 AS-Level 成绩，评估 A-Level 预测分
- 浏览各院校官网，看不同专业要求
- 和家人讨论城市偏好、预算、专业方向
- 开始制作粗略的选校 Excel 表格

### 情绪状态
🤔 纠结（选英国还是香港？选 UCL 还是爱丁堡？）
📊 理性（开始做功课）

### 痛点
- 不知道自己的分数能申哪些学校
- 院校官网信息分散，需要开 20 个标签页对比
- 不了解不同专业之间的申请难度差异
- 误信中介"包进"话术

### 平台介入机会
- **成绩匹配引擎**：输入预测分 → 输出匹配院校列表（含录取概率区间）
- **院校对比工具**：横向对比学费/排名/要求/城市
- **选校 Shortlist**：收藏并管理候选院校，家长可同步查看
- **"冲稳保"分类**：自动将 Shortlist 按录取概率分层

---

## 阶段三：材料准备（Year 12 暑假 – Year 13 上学期，6 月–11 月）

### 学生行为
- 备考 IELTS / TOEFL
- 开始写个人陈述（Personal Statement）初稿
- 联系学校推荐老师
- 整理课外活动、竞赛、实习记录
- 准备 LNAT / BMAT 等入学考试（视专业）

### 情绪状态
😓 压力大（PS 写了删、删了写；学业+申请双重压力）
😟 不确定（不知道自己的 PS 好不好）

### 痛点
- PS 不知道该写什么角度、结构如何
- 不知道有没有踩 UCAS 的红线（字数/格式/版权）
- 和推荐老师沟通困难（老师不了解 UCAS 推荐信格式）
- 不知道哪些课外活动值得写

### 平台介入机会
- **PS 结构化编辑器**：引导分模块填写，避免遗漏关键内容
- **字符计数 + 格式检查**：实时提示不超限、无违规格式
- **AI 润色反馈**：指出逻辑问题、重复表达（不代写）
- **PS 案例库**：按专业/院校筛选往届脱敏样本
- **推荐信引导模板**：给老师提供 UCAS Reference 格式说明和内容框架

---

## 阶段四：提交申请（Year 13 上学期，9 月–1 月）

### 学生行为
- 在 UCAS Hub 注册并填写申请表
- 填写教育经历、考试预测分
- 粘贴 PS、确认推荐信已提交
- 缴费（£27.50）提交申请
- 对于 Oxbridge/医学：10 月 15 日前提交 + 参加笔试/面试
- 对于香港院校：各校独立系统分别提交

### 情绪状态
😬 紧张（怕填错 / 错过 deadline）
✅ 提交后短暂轻松

### 痛点
- UCAS 表格界面对中文用户不友好
- 不确定预测分填多少合适（填高了怕打脸）
- 同时管理多所香港院校的独立申请系统，极易漏掉
- 不知道推荐信有没有成功提交

### 平台介入机会
- **UCAS 填表逐步指南**：截图级手把手教程（中文）
- **申请截止日历**：基于 Shortlist 自动生成，微信提醒
- **任务看板**：每所院校独立进度追踪（未开始/进行中/已提交）
- **香港申请聚合器**：将 8 所院校申请要求和链接汇聚一处
- **预测分建议**：根据往届数据给出合理填写范围

---

## 阶段五：等待决定（Year 13 下学期，2 月–7 月）

### 学生行为
- 陆续收到各院校 Offer / Rejection
- 在 UCAS Track 追踪申请状态
- 等待 A-Level 成绩（8 月放榜）
- 决定 Firm（第一志愿）和 Insurance（保底志愿）
- 若 UCAS 申请落败，考虑 Clearing

### 情绪状态
😨 煎熬（等通知的焦虑）
🎉 收到 Offer 时极喜
😞 被拒时沮丧

### 痛点
- 不知道条件 Offer 要求的分数是否能达到
- 不了解 Clearing 流程，临时抱佛脚
- 家长和学生对 Firm/Insurance 选择分歧

### 平台介入机会
- **Offer 管理看板**：汇总收到的 Offer，一键对比
- **条件达成概率分析**：根据模拟考数据评估条件 Offer 达成可能性
- **Clearing 指南**：提前告知流程，8 月放榜后立即推送
- **Firm 决策辅助**：对比两个 Offer 的关键维度（排名/学费/城市/专业）

---

## 阶段六：录取后准备（Year 13 暑假，8 月–9 月）

### 学生行为
- 确认无条件 Offer，接受并缴纳押金
- 申请英国 Student Visa 或香港学生签证
- 准备结核检测、财力证明
- 订机票、找住宿、购置物品
- 办理银行卡、国际汇款事宜

### 情绪状态
🎊 兴奋
😅 事务繁杂

### 痛点
- 签证材料清单不清楚，怕遗漏
- 不知道财力证明需要多少钱
- CAS 号如何获取不了解

### 平台介入机会
- **签证步骤指南**（UK / HK 各一套）
- **财力证明计算器**：学费 + 生活费 = 所需存款额
- **行前清单**：住宿 / 银行 / 通讯 / 保险 全套 checklist
- **社区**：在英/港在读学长答疑

## 关键情绪曲线

```
情绪值
高 │          ★收 Offer
   │         /         \
   │        /           ★接受 Firm
中 │       /   ★PS完成  \         ★拿到签证
   │      /              \        /
低 │ ★迷茫 ★PS折磨   ★等待煎熬
   └──────────────────────────────────────
     认知   选校   材料   提交   等待   录取后
```

> **设计启示**：在"材料准备"和"等待"两个低谷期，平台需要提供最多支持和陪伴感（进度提示、社区互动）来降低焦虑、提高留存。
