# 全站错因诊断与智能讲题

## 目标

把一次作答从“得分 + 标准答案”升级为可执行的复习判断。诊断只使用学生已经产生的得分和行为证据，不把单次错误直接解释为固定能力缺陷。

## 已接入的结果页

- 专项练习完成页；
- 客观固定卷即时成绩页；
- 书面固定卷评分报告；
- 历史练习与模考记录。

历史记录无需迁移。系统直接使用既有 `ExamAnswer` 中的得分、首选答案、最终答案、作答时间、改答次数、访问次数、标记状态、书面作答和评分反馈生成诊断。

## 诊断类型

| 类型 | 主要证据 | 默认补救 |
| --- | --- | --- |
| 稳定掌握 | 满分且没有明显犹豫信号 | 按正常间隔复习 |
| 答对但不稳 | 满分，但多次改答、标记或明显超时 | 重述关键步骤并做变式 |
| 未完成 | 没有完整答案或书面作答 | 补基础方法后限时重做 |
| 作答过快 | 错误且用时显著短于建议核对时间 | 加入提交前核对 |
| 改对为错 | 首选正确、最终改错 | 记录改答依据 |
| 推理不稳定 | 错误且反复改答、回看或标记 | 拆解已知、目标和规则 |
| 知识或方法缺口 | 正常用时内稳定选择错误方法 | 先学知识点，再做两道同类题 |
| 过程不完整 | 客观题部分得分或书面题只有部分过程分 | 补全推导并重写 |
| 关键步骤缺失 | AI 评分明确返回缺失评分点 | 逐项补写并做同结构变式 |

## 讲题与补救

- 每道问题展示诊断标签、可见证据和下一步动作。
- 错题可直接进入对应知识讲解或同知识点自适应训练。
- 客观题支持 `optionExplanations` 人工逐选项解析；未配置时使用明确标注的标准解法核对提示，不伪造具体错因。
- 一旦某题开始配置人工逐选项解析，题库门禁要求覆盖全部选项；空内容为 critical，缺项为 warning。
- 书面题复用 AI 评分中的 `keyStepsMissing`，直接展示缺失评分点，不再只给笼统总评。

## 数据可靠性

- 匿名学生仍可使用即时诊断，但系统不会请求受保护的成绩写入接口。
- 登录学生的成绩写入带客户端一次性保护，避免 React 开发模式重复保存同一场考试。
- 错因是复习线索，不作为招生结果、能力标签或心理判断。

## 发布检查

```powershell
pnpm test
pnpm audit:questions
pnpm build
```

浏览器验收覆盖桌面端与 390px 手机宽度，要求无横向溢出、无控制台错误，并确认诊断摘要、逐题证据和补救链接可见。
