## 自动化守门

运行：

```bash
pnpm audit:esat
pnpm audit:questions
pnpm test
pnpm build
```

`audit:esat` 会对套卷数量、模块数量、题量、时长、选项、答案、题目 ID、重复提示、重复模板、难题比例、答案位置、科目配比和补齐模块主题配比执行封库检查。任何 critical 或 warning 都会令命令失败。
