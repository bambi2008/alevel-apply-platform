# 商业模式与定价方案

**产品**：A-Level 英国/香港大学申请 SaaS 平台
**商业模式**：SaaS 订阅（To-C 主，To-B 辅）

---

## 一、收入来源结构

```
Phase 1 收入（工具订阅 + 笔试备考加购）
├── C 端订阅：Free / Standard（¥299）/ Pro（¥899）
└── 笔试备考加购：LNAT / UCAT / MAT 等（¥399–¥799/季）

Phase 2 新增收入（社区生态 + 资源市场）
├── 背景提升资源市场：资源方入驻佣金（CPS 10–15% 或年费）
├── B 端学校授权：批量席位
└── 社区高级权限：含于 Pro，驱动续费

> ⚠️ 人工辅导（导师 1v1）列为 Phase 3，一期二期均不上线。
```

---

## 二、C 端定价方案

### 2.1 分层套餐

| 套餐名 | 价格 | 目标用户 | 核心权益 |
|--------|------|---------|---------|
| **免费体验版** | ¥0 | 探索期用户 | 成绩匹配（仅看前 5 结果）、院校基础信息查询、1 份 PS 草稿保存 |
| **标准版 Standard** | ¥299 / 年 | 预算敏感型学生 | 完整选校匹配、全量院校数据库、申请日历、任务管理、PS 编辑器（无限版本） |
| **专业版 Pro** | ¥899 / 年 | 主流目标用户 | 标准版全部 + AI PS 润色（20 次/月）、往届案例库（全开放）、Offer 对比分析、社区高级权限、签证指南 PDF |
~~**旗舰版 Premium** ¥1,999 / 年~~ → **暂缓，移至 Phase 3**（需人工导师资源）

> **战略定价逻辑**：一期以 Pro 为顶档主推，目标占付费用户 65%+。笔试备考加购与订阅同期上线，显著提升 ARPU。

### Phase 1 加购模块（与工具集同步上线）

| 加购模块 | 价格 | 说明 |
|---------|------|------|
| **笔试备考 - LNAT** | ¥399 / 季度 | 题库 + 模拟考 + 解析，替代 ¥8,000–¥15,000 线下班 |
| **笔试备考 - UCAT** | ¥499 / 季度 | VR/QR/AR/SJT 四模块专项训练 |
| **笔试备考 - MAT/TMUA** | ¥399 / 季度 | 数学方向专项 |
| **笔试备考 - 全科通票** | ¥799 / 季度 | 覆盖所有考试（含未来新增） |
| **择校对比看板** | 含于 Pro 及以上 | 定性多维展示，不给推荐结论 |

> 笔试备考加购的战略意义：用户基数中约 15–20% 需要考 LNAT/UCAT，单科加购客单价 ¥399，远高于订阅本身，且竞品定价 10–20 倍。

### Phase 2 新增收入模块

| 模块 | 商业模式 | 说明 |
|------|---------|------|
| **社区案例库** | 含于 Pro，驱动续费 | 往届真实录取案例，按院校/专业/成绩筛选 |
| **背景提升资源市场** | 资源方按成交抽佣 10–15% 或年度入驻费 | 学生免费浏览，平台不向学生额外收费 |
| **B 端学校授权** | 批量席位年费 | 见第三节 B 端定价 |

### 2.2 月费选项（仅 Standard / Pro）

- Standard 月费：¥39 / 月
- Pro 月费：¥109 / 月
- 说明：月费面向观望期用户，年费换算更优惠（年费约等于 8 个月月费）

### 2.3 早鸟与优惠策略

| 优惠类型 | 折扣 | 条件 |
|---------|------|------|
| 早鸟价（产品上线前 3 个月） | 7 折 | 预付年费 |
| 学生认证折扣 | 9 折 | 提供在校证明（长期） |
| 好友邀请返现 | 被邀者注册后，邀请人获 ¥50 余额 | 无上限 |
| 学校批量采购（5 人以上） | 8.5 折 | 联系商务 |

## 五、收入预测模型

### 5.1 假设条件

| 假设 | 数值 |
|------|------|
| 大陆 A-Level 学生每年申请人数 | ~60,000 人 |
| 平台初期可触达比例（Year 1） | 2% → 1,200 人注册 |
| 付费转化率 | 35% → 420 人 |
| 套餐分布（付费中） | Standard 35% / Pro 65%（无 Premium） |
| 平均客单价（付费用户加权） | ~¥680 |

### 5.2 三年收入预测

| 年份 | 注册用户 | 付费用户 | 平均客单价 | 年收入 | B 端收入 |
|------|---------|---------|----------|-------|---------|
| Year 1 | 3,000 | 900 | ¥680 | **¥61 万** | ¥0 |
| Year 2 | 12,000 | 3,500 | ¥750 | **¥263 万** | ¥50 万 |
| Year 3 | 35,000 | 10,000 | ¥800 | **¥800 万** | ¥200 万 |

> **盈亏平衡测算**：若团队 3 人（产品+开发+运营），月运营成本约 ¥5 万，年成本约 ¥60 万 + 服务器/API 约 ¥10 万 = ¥70 万 / 年。Year 1 末期可接近盈亏平衡。

### 5.3 关键增长杠杆

- 每年 8 月放榜后，次年申请季开始，是获客高峰（6 月–9 月）
- 口碑传播：一位用户 → 平均推荐 2 位同学（A-Level 圈子小）
- 内容 SEO：知乎/小红书"A-Level 申请"关键词长尾流量

## 七、护城河建设路径

```
阶段 1（0–12 月）：数据护城河
→ 建立最全 A-Level 院校数据库（UK + HK）
→ 积累真实往届录取数据

阶段 2（12–24 月）：社区护城河
→ 往届学生 Offer 案例库（唯一性数据）
→ 用户生成内容（UGC）形成内容壁垒

阶段 3（24–36 月）：B 端护城河
→ 与学校签订长期合同
→ 教师端数据形成切换成本

长期：品牌护城河
→ 成为大陆 A-Level 圈默认选择
→ 往届成功案例成为最好的营销素材
```
