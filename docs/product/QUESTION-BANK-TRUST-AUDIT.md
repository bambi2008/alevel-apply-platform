# 全站题库正确性与解析可信度封库报告

## 封库结论

- 审计范围：10 项考试、2,540 道题、106 套试卷。
- 主题覆盖：所有考试均达到全部已定义主题覆盖。
- 最终结果：0 critical，0 warnings。
- 发布门禁：`pnpm audit:questions` 遇到任意 critical 或 warning 都会以失败状态退出。

## 自动审计范围

现有结构化审计继续检查题目 ID、主题归属、分值、选项、答案、解析、套卷引用、题量与主题覆盖。本次新增语义风险审计，并同时扫描主题库与固定套卷中的题目：

- 多个选项同时被解析声明为正确或等价；
- 标准答案与解析中的答案声明冲突；
- 解析承认没有选项准确匹配，只选择“最接近”答案；
- 解析含有临时改题、修正条件或答案键错误说明；
- 解析残留 `wait`、`recompute`、`hmm` 等自我纠错草稿。

## 本次修复

- MAT：消除等价重复选项，修正答案键和数值条件；重做圆与抛物线四交点参数及面积；清理长题推导草稿。
- ESAT：消除等价或重复选项；补回微分方程特解的正确选项；修正电路、行列式和原子能级计算解析。
- STEP：统一积分、曲线、双曲线和不等式题的题干与解法；修正不可能条件、错误界与三角方程根；将试探式推导改为可逐步核验的证明。

## 质量边界

自动审计可以稳定阻止已知结构错误和高风险措辞重新进入题库，但不能代替每道新题的人工数学复核。今后新增或修改题目仍应同时完成：

1. 出题人独立作答；
2. 第二人核对题干、唯一答案和解析；
3. 运行 `pnpm audit:questions`；
4. 运行全量测试和生产构建；
5. 上线后依据真实作答数据校准难度，不反向修改正确答案。
