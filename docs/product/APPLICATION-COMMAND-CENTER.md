# 申请材料完整性与提交作战室

## 目标

把申请列表、资料库、待办和消息中心连接成一条可执行的提交链路。学生能看到每份申请缺什么、哪些文件已经绑定、什么条件满足后才能确认提交，而不是仅手动修改申请状态。

## 核心规则

- UCAS 与香港直申使用不同材料模板。
- 就绪度只计算必需材料；可选材料可以留空或豁免。
- 文件过期后，所有引用该文件的申请材料自动变为“需更新”。
- 上传新版本时可以指定上一版本，所有现有绑定自动迁移到新版本。
- 只有必需材料全部就绪且申请费已确认，才能记录申请已提交。
- 确认提交会记录提交时间、申请编号和审计日志。

## 推荐信协作

- 学生为 UCAS 申请生成 14 天安全链接，并自行发送给推荐人。
- 原始令牌仅在创建时返回，数据库只保存 SHA-256 哈希。
- 推荐人不需要账户，只能看到学生姓名、申请项目和学生留言。
- 链接可撤销、会过期，只接受不超过 10 MB 的 PDF、DOC 或 DOCX。
- 上传成功后，文件进入学生资料库，推荐信材料自动完成并写入审计日志。

## 数据联动

- 每份申请自动维护一条“完成申请材料”待办。
- 待办截止日期优先使用专业截止日，其次使用院校主要截止日。
- 材料齐全后待办自动完成；临近截止时由现有消息中心提醒。
- `ApplicationDocument` 保留申请与实际文件的最终关联，用于后续生成提交包。

## 发布

```bash
pnpm exec prisma migrate deploy
pnpm exec prisma generate
```

生产环境启用推荐信上传前，需要把本地存储适配器替换为带私有访问控制的对象存储，并设置病毒扫描与文件保留策略。
