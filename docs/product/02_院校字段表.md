# 院校数据库字段表（UK + HK）

> 本文档定义平台院校数据库的标准字段结构，供开发团队建表及数据录入使用。

---

## 一、字段规范

### 1.1 院校基础信息

| 字段名（英文） | 字段名（中文） | 类型 | 说明 / 枚举值 |
|--------------|-------------|------|------------|
| `uni_id` | 院校 ID | UUID | 主键 |
| `name_en` | 英文名称 | String | 官方英文全称 |
| `name_zh` | 中文名称 | String | 简体中文常用译名 |
| `country` | 所在地区 | Enum | `UK` / `HK` |
| `city` | 城市 | String | 如 London、Edinburgh、Hong Kong |
| `league` | 联盟/分组 | Enum | `Russell Group` / `Top 24` / `Million+` / `HK UGC 8` |
| `qs_rank_world` | QS 世界排名 | Integer | 年度更新 |
| `qs_rank_subject` | QS 学科排名 | JSON | 如 `{"Computer Science": 5, "Law": 12}` |
| `ucas_code` | UCAS 院校代码 | String(1) | 如 `O` = Oxford（仅 UK） |
| `official_url` | 官网 | URL | |
| `admissions_url` | 招生页 URL | URL | |
| `logo_url` | Logo 图片 | URL | |

### 1.2 申请系统信息

| 字段名 | 字段名（中文） | 类型 | 说明 |
|--------|-------------|------|------|
| `application_system` | 申请平台 | Enum | `UCAS` / `Direct` / `Both` |
| `ucas_institution_code` | UCAS 机构代码 | String | 四位字母代码，如 `OXFD` |
| `application_portal_url` | 申请入口链接 | URL | 直申院校使用 |
| `application_fee_hkd` | 申请费（港元） | Integer | 香港院校 |
| `application_fee_gbp` | 申请费（英镑） | Integer | 英国院校（UCAS 统一收费） |
| `max_choices` | 最大志愿数 | Integer | 英国为 5，香港无限制标为 -1 |

### 1.3 申请截止日期

| 字段名 | 中文 | 类型 | 说明 |
|--------|------|------|------|
| `deadline_early` | 早申截止 | Date | 如 Oxford: 2025-10-15 |
| `deadline_main` | 主申截止 | Date | 多数英国课程: 2026-01-29 |
| `deadline_late` | 晚申截止 | Date | Clearing / HK 晚申 |
| `open_date` | 申请开放日 | Date | |
| `result_release_date` | 录取结果预计发放 | Date | 范围可填 date_from + date_to |

### 1.4 入学要求

| 字段名 | 中文 | 类型 | 说明 |
|--------|------|------|------|
| `alevel_minimum` | A-Level 最低要求 | String | 如 `AAA`、`A*AA` |
| `alevel_required_subjects` | 必修科目 | Array[String] | 如 `["Mathematics", "Chemistry"]` |
| `alevel_preferred_subjects` | 推荐科目 | Array[String] | |
| `alevel_excluded_subjects` | 不接受科目 | Array[String] | 如部分校不接受 General Studies |
| `as_level_required` | 是否需要 AS 成绩 | Boolean | |
| `epq_considered` | 是否考虑 EPQ | Boolean | |
| `gcse_minimum_english` | GCSE 英语最低 | Integer | 如 `6` |
| `gcse_minimum_maths` | GCSE 数学最低 | Integer | |
| `ib_minimum` | IB 最低分 | Integer | 备用字段 |
| `sat_accepted` | 是否接受 SAT | Boolean | |

### 1.5 语言要求

| 字段名 | 中文 | 类型 | 说明 |
|--------|------|------|------|
| `ielts_overall` | 雅思总分要求 | Float | 如 `6.5` |
| `ielts_writing` | 雅思写作小分 | Float | |
| `ielts_speaking` | 雅思口语小分 | Float | |
| `ielts_listening` | 雅思听力小分 | Float | |
| `ielts_reading` | 雅思阅读小分 | Float | |
| `toefl_minimum` | 托福最低分 | Integer | |
| `language_exemptions` | 语言豁免条件 | String | 如"A-Level English Language A" |

### 1.6 专业字段（Courses 子表，关联院校）

| 字段名 | 中文 | 类型 |
|--------|------|------|
| `course_id` | 课程 ID | UUID |
| `uni_id` | 关联院校 | FK |
| `course_name_en` | 课程英文名 | String |
| `course_name_zh` | 课程中文译名 | String |
| `ucas_course_code` | UCAS 课程代码 | String(4) |
| `duration_years` | 学制（年） | Integer |
| `degree_type` | 学位类型 | Enum | `BA` / `BSc` / `BEng` / `LLB` / `MBChB` |
| `annual_tuition_gbp` | 年学费（英镑） | Integer |
| `annual_tuition_hkd` | 年学费（港元） | Integer |
| `alevel_offer_typical` | 典型成绩要求 | String | 如 `AAB` |
| `alevel_offer_minimum` | 最低成绩要求 | String | 如 `ABB` |
| `required_subjects` | 必须科目 | Array[String] | |
| `admissions_test` | 入学考试 | String | 如 `LNAT`、`BMAT`、`MAT` |
| `interview_required` | 是否面试 | Boolean | |
| `scholarship_available` | 是否有奖学金 | Boolean | |
| `scholarship_url` | 奖学金链接 | URL | |
| `course_page_url` | 课程官方页面 | URL | |
| `accepts_gap_year` | 是否接受间隔年 | Boolean | |
| `mode` | 学习模式 | Enum | `Full-time` / `Part-time` |

### 1.7 录取数据（历史参考，每年更新）

| 字段名 | 中文 | 类型 |
|--------|------|------|
| `acceptance_rate` | 录取率 | Float | |
| `avg_offer_grade` | 平均给分 | String | |
| `intl_student_ratio` | 国际生比例 | Float | |
| `mainland_china_cohort` | 大陆生历史录取人数 | Integer | 年度 |
| `data_year` | 数据年份 | Integer | |
