# 全站模考成绩报告与能力画像

## 目标

把一次考试记录转化为可解释、可比较、可行动的学生报告。报告适用于专项练习、随机模拟、固定客观卷与固定书面卷，并复用同一套证据口径。

## 报告内容

- 原始得分、得分率、完成度和用时。
- 固定套卷的分模块表现。
- 知识点得分、平均难度和补强优先级。
- 难度 1/2/3 的分层表现。
- 改答、回看、标记、过快作答和答对但不稳等行为信号。
- 同卷优先、同模式回退的历史趋势。
- 基于题量与历史波动的训练表现区间。
- 连接知识讲解、自适应练习和限时训练的下一轮处方。

## 证据边界

“平台训练表现区间”不是官方换算分、排名、录取概率或正式成绩预测。区间使用本次样本量、得分率及可比历史波动生成，并向学生展示置信度与可比记录数。

历史比较优先使用同一固定套卷的重复作答。没有足够同卷记录时，回退到同一考试、同一练习模式的得分率；页面会明确提示题量与题目可能不同。

时间压力判断依赖 `timeUsedSec`、逐题计时覆盖和未答题数量。逐题行为覆盖不足时，报告保留结果，但降低措辞强度并显示数据质量说明。

## 路由与权限

- 学生页面：`/[locale]/tests/[testId]/history/[sessionId]`
- 数据接口：`/api/exam-sessions/[id]/report`

接口通过当前登录用户对应的 `StudentProfile` 限定 `ExamSession`，不可读取其他学生记录。

## 数据与部署

本工程复用现有 `ExamSession` 和 `ExamAnswer` 字段，不需要新增 Prisma migration。历史记录中的题目通过静态题库 `questionId` 还原；已下架题目会列入数据完整性说明，不进入知识点和错因画像。

## 验收

1. 未登录访问报告 API 返回 `401`。
2. 非本人会话返回 `404`。
3. 主要答题入口在记录保存成功后显示“查看完整报告”。
4. 桌面端、手机端和打印模式均无横向溢出。
5. 区间文案不得宣称官方换算、排名或录取预测。
